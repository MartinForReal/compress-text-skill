## Compressed text: Project startup

1. Install Node 20.
2. Copy `.env.example` to `.env`.
3. In `.env`, set:
   - `DATABASE_URL` to your Postgres instance.
   - `PORT` if needed; default is 8080.
4. Run `npm start`; the app listens on `PORT`.

If startup fails, check `DATABASE_URL` first; most failures are missing or incorrect values.
