## Compressed text: Setup

## Setup
- Install Node 20.
- Copy `.env.example` to `.env`.

## Configuration
In `.env`:
- Set `DATABASE_URL` to your Postgres instance.
- Set `PORT` if needed; default is 8080.

## Running
After setup, run `npm start`; the app uses the configured `PORT`.

## Troubleshooting
If the app will not start, check `DATABASE_URL`; most start-up failures come from a missing or wrong value.
