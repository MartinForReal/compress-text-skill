## Compressed text: Project setup and run

### Setup
1. Install Node 20.
2. Copy `.env.example` to `.env`.
3. Set `DATABASE_URL` in `.env` to your Postgres instance; set `PORT` (default `8080`).

### Run
Run `npm start`; the app starts on configured `PORT`.

### Troubleshooting
If startup fails, check `DATABASE_URL`; missing/wrong values cause most failures.
