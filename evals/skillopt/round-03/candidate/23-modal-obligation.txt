## Compressed text: Payments API integration guidelines

Payments API clients:
- Must authenticate every request with a valid API key; requests without one are rejected.
- Must never log the full card number.
- Should retry 503 failures with exponential backoff because 503 means the service is temporarily unavailable, and should show users the API's decline reason when a payment is declined.
- May cache successful GET responses for up to 60 seconds to reduce load, and may use the v2 or v3 endpoint; v3 is recommended.
