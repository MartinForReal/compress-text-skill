## Prompt

Compress this onboarding note. Keep it readable.

## Input

Welcome to the platform onboarding. All new employees sign in through Single Sign-On (SSO);
after the first login, Single Sign-On remembers your session for the rest of the day. We
require Multi-Factor Authentication (MFA) on every account, so please set up Multi-Factor
Authentication on your first day. User accounts are provisioned automatically through System
for Cross-domain Identity Management (SCIM) from the HR system, so there is no manual signup.
If Single Sign-On ever fails, contact the help desk; if Multi-Factor Authentication is lost,
the help desk can reset Multi-Factor Authentication for you. Our Service Level Agreement
(SLA) for help-desk tickets is one business day.
